# 狗了个狗

狗狗主题的三消堆叠网页小游戏，玩法和《羊了个羊》一样：点亮着的牌，它会飞进底部 7 格卡槽，凑齐 3 张相同就消除；卡槽塞满 7 张就输，清空全场就赢。

整个游戏只有一个 HTML 文件，不依赖任何外部资源：16 种图案、6 种狗狗、背景音乐和全部音效都由代码实时生成，国内网络也能秒开。

## 在线玩

- 公开链接（GitHub Pages）：https://kline-x.github.io/gou-le-ge-gou/
- 另有 claude.ai Artifact 版（作者私有，分享后可看）。在 claude.ai 里打开时，会多出在线狗友和 AI 狗评两项功能。

## 玩法

| 元素 | 说明 |
|---|---|
| 层叠牌堆 | 被压住的牌会变暗，点不了；先拿上面的 |
| 盲盒牌堆 | 第 2 关底部两侧各一堆，只能拿最上面那张 |
| 移出 | 卡槽最左边 3 张挪到移出区，那里的牌随时可以拿回来 |
| 撤回 | 最后一步放回原处；如果上一步刚好消除了，就不能撤回 |
| 洗牌 | 场上的牌位置不变、图案重排，并且尽量保证重排后仍然有解 |
| 复活 | 输了可以用一次，效果等于移出 3 张 |

- 每个道具每关只能用 1 次。
- **今日挑战**：同一天所有人玩的是同一关（种子是 `dog-v1-年-月-日`，其中 v1 是生成器版本）。第 1 关是热身；第 2 关有 16 种图案、192 张牌、12 层。
- **自由练习**：分简单、普通、困难、原味地狱四档，其中「原味地狱」不保证有解，致敬原版。

## 关卡保证有解

生成关卡的步骤：
1. 先搭出分层、左右对称的结构。
2. 模拟一条合法的拿牌路径：每一步只拿当时没被压住的牌，并且让卡槽里始终不超过 6 张。
3. 沿着这条路径分配图案。

这样生成的每一关都至少有一条不用道具就能通关的解。要想难，靠的是：
- 路径会优先去挖刚露出来的牌；
- 在多个候选关卡里，挑贪心机器人最难打的那一个。

用 `npm run balance` 可以复现下面的平衡数据（贪心机器人玩 300 局，允许使用道具时的通关率）：

| 难度 | 通关率 |
|---|---|
| 第 1 关、简单 | 100% |
| 普通 | 74% |
| 困难 | 45% |
| 第 2 关 | 23% |

## 本地开发

零 npm 依赖，只需要 Node ≥ 18：

```bash
npm test
```

```bash
npm run build
```

```bash
npm run serve
```

- `npm test`：运行 node:test 单元测试。
- `npm run build`：输出 `dist/index.html`（完整网页）和 `dist/artifact.html`（Artifact 片段）。
- `npm run serve`：启动本地预览，地址是 http://localhost:5301/。

在地址后面加 `?debug`，可以在控制台使用 `__dog`：

| 方法 | 作用 |
|---|---|
| `__dog.level('daily2')` | 直接进入某一关 |
| `__dog.step()` | 按已知解走一步；偏离已知解后改由机器人走 |
| `__dog.autoplay(120)` | 按给定的毫秒间隔自动玩 |
| `__dog.state()` | 查看当前局面 |

另外，`?seed=xxx` 可以固定自由练习的种子。

## 目录

| 路径 | 内容 |
|---|---|
| `src/core` | 纯逻辑：随机数、布局、有解分配、关卡生成、对局状态机、贪心机器人 |
| `src/art` | 16 种图案、6 个犬种 × 6 种表情的狗头、手绘笔画字标（都是 SVG 字符串） |
| `src/audio` | WebAudio 实时合成的音效、原创背景音乐和紧张声部 |
| `src/ui` | 存档、claude.ai 平台能力、粒子特效、战绩图、牌面动画、界面、主流程 |
| `build.mjs` | 把模块包成闭包、内联成单文件，并校验没有外部资源 |
| `docs/superpowers` | 设计文档与实施计划 |
